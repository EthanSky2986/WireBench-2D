# 架构与模型边界

WireBench-2D 是本地浏览器中的二维接线实验台。采用 React、TypeScript 与 SVG，核心仿真不依赖浏览器。资料和照片用于核对器件、端子和外观；功能范围以项目需求为准。

## 模块职责

| 文件                                     | 职责                                                   | 不应承担的职责                       |
| ---------------------------------------- | ------------------------------------------------------ | ------------------------------------ |
| `src/sim/model.ts`                       | 器件、端子、触点、负载与预留端子的唯一电气定义         | 屏幕位置、样式、浏览器存储           |
| `src/sim/engine.ts`                      | 根据接线、操作输入、电源状态和先前线圈状态计算稳定结果 | 按示例名称直接切换灯或接触器         |
| `src/sim/simulationState.ts`             | 纯状态转换，统一处理通断电、输入、换线、复位和瞬动释放 | 浏览器事件监听、绘图                 |

| `src/components/ResetMenu.tsx`           | 电源旁的复位/清空操作菜单及其键盘、焦点行为            | 自行修改导线或执行电气计算           |
| `src/components/Modal.tsx`               | 原生模态隔离、关闭和触发按钮焦点恢复                   | 改动背景接线或接管仿真               |
| `src/autosave.ts` / `useProjectAutosave` | 延迟保存、离开页面前写入待保存自主稿、计时器清理       | 将示例写入自主稿或绕过存档保护       |
| `src/i18n/catalog.ts` / 中英文子词表     | 类型安全的文案定义、纯翻译与参数插值                   | 浏览器状态、电气逻辑                 |
| `src/i18n/messages.ts`                   | 结构化消息代码、参数与纯格式化适配器                   | 按中文句子猜测错误类型               |
| `src/i18n/provider.tsx`                  | React 翻译上下文、语言偏好与页面 lang                  | 改写项目存档或电气标识               |
| `src/App.tsx`                            | 组织接线编辑、仿真调用、历史记录、存储与界面反馈       | 复制一套触点连接规则                 |
| `src/styles.css` / `src/main.tsx`        | 样式 / 应用入口                                        | 电气逻辑                             |

依赖方向是“界面使用领域模型”，`sim` 不导入 React、布局或存档界面。可复用的仿真规则优先放在 `sim`；只影响显示或操作手感的规则留在界面。

`src/storage.ts` 独立负责浏览器存档的读取和覆盖保护，接受可替换的存储接口；自主稿的自动保存与手动保存统一调用 `saveStoredProject`，不用界面内的直接 `localStorage.setItem` 绕过保护。示例练习中的保存按钮执行文件导出，不写入自主稿存储。

`useProjectAutosave` 只接收自主稿，平时使用 500 毫秒延迟；在 `pagehide` 和文档隐藏时通过 `createProjectAutosave.flush()` 同步写入待保存内容。一次待保存内容只写一次；组件清理取消计时器，不额外写入，避免开发模式重复挂载产生副作用。保护状态、写入失败反馈继续由存储层处理。

## 数据怎样流动

1. 用户编辑产生 `Wire[]`：每根导线由稳定的 `id`、`from`、`to`、`color` 和可选 `points` 组成。
2. 器件操作产生 `inputs`；`true` 表示按钮按下、行程开关触发、急停保持或热继电器测试跳闸。
3. `simulate(wires, inputs, powered, previousCoils)` 计算线圈、灯、闭合触点、端子连接到哪条电源母线，以及故障。
4. 界面绘制这个结果。下一次操作保留上次的线圈状态供自锁回路继续计算；断电将线圈恢复为释放状态。

上述操作经 `useSimulation` 进入 `simulationReducer`，由纯状态转换保存先前线圈状态并调用引擎。窗口失焦或页面隐藏转换为瞬动按钮释放事件，避免鼠标松开事件丢失时按钮保持按下。

接线数据、瞬时运行状态和视图状态分别管理。存档保存方案名称及用户导线，不保存通电状态、按住的按钮或运行中的线圈。导入、恢复方案后应从断电状态开始。

`ResetMenu` 位于电源按钮旁。「复位运行状态」调用 `resetSimulation(wires)`，断电、清除故障并复位按钮、SQ、FR 和急停等所有输入，不提交接线变更，保留当前名称、示例会话以及撤销/重做历史。「清空全部接线」先显示确认框，确认后向当前稿提交空 `Wire[]` 并复位仿真；保留名称和当前会话，清空操作可以撤销。普通断电只释放线圈并清除故障，机械输入位置仍保留，不能代替完整复位。

## 自主稿与示例练习

`workspaceReducer` 是不依赖 DOM 或浏览器存储的纯状态转换。`workbench` 保存自主稿；`example` 为可空的独立内存练习稿，各自包含名称和 `past/present/future` 接线历史。`currentWorkspace` 决定当前编辑目标，提交、撤销、重做及改名只作用于当前稿。模板导线和自定义拐点复制到练习稿，避免修改模板或原稿。

进入示例保留完整自主稿及其历史。切换到不同示例从对应模板新建练习，不恢复前一个示例的修改。当前实验条提供「退出实验」，全屏时仍可用；再次点击已选中示例卡片或点击「自主接线」也退出。退出丢弃练习稿、恢复原自主稿与原有撤销/重做历史，并复位仿真；进入示例不是自主稿的一次接线提交，返回原稿应使用退出操作。

自动保存的唯一目标是 `workbench` 的名称和当前导线。示例会话、示例修改以及两套撤销/重做历史均不写入存档；示例中的保存按钮和导出按钮都导出当前练习。刷新后从已保存的自主稿启动，练习结果需要事先导出。自主稿的存储错误及损坏原文保护仍使用原有策略。

导入校验成功后，`replace-project` 将导入的名称和导线作为新的自主稿，并退出示例。导入前自主稿的当前线路进入其撤销历史，因此可以撤销恢复线路；名称不属于接线历史。导入失败不改变当前稿。

## 连接关系的约束

- 完整端子 ID 使用 `器件ID:端子标签`，例如 `KM1:A1`，以 `model.ts` 中的定义为准。修改显示名称、移动器件不能改变 ID。
- 导线只通过 `from` 和 `to` 形成连接。交叉、重叠、坐标相同、视觉上擦过端子、拐点经过其他导线均不会新增连接。
- 颜色和线条动画仅用于识别与显示；红色线不自动代表 L，蓝色线不自动代表 N。电源连接状态由网络计算。
- 固定引出线采用一对一的逻辑映射：端子排上 `KM1:A1` 对应器件的 `KM1:A1`。当前不另建一组可编辑的器件螺钉节点，固定配线不进入用户 `Wire[]`。显示或隐藏固定引出线不会改变仿真。
- SQ 固定线只绘制端子孔到下方横槽的短引线，入槽后的内部线路继续隐藏；其端子和用户接线仍按同一模型计算。横槽位置使用 `CONTROL_RAIL_Y`，短引线终点随它确定。SB1/SB2/SB3/ESTOP 的 14 个端子连续安装于同一底座，分组从模型端子列表生成；底座相邻、组间分隔及 OP 展示标记均不改变电气连接或存档 ID。
- 图形中的固定引出线路径用于辨认对应器件，并不是毫米级实物布线还原。后续若引入跨端子桥接、一对多端子或可拆固定线，应在电气模型中明确新增映射，并测试连接关系；不能依赖 SVG 路径位置。
- 急停、按钮和热继电器只改变本器件的触点。是否停止某回路取决于实际接线，不根据器件名字全局关闭负载。热继电器跳闸不直接断开其三相主通道。

## 仿真准确性边界

当前是理想开关与继电器逻辑模型：合并导线和闭合触点，判断负载是否独立跨接教学控制电源，再迭代到稳定线圈状态。`L`、`N`、`floating` 表示与母线的连接关系，**不是测得的电压值**。

教学电源 L/N 没有绑定实物电压、频率、线圈额定值或吸合阈值。界面和说明不得将这些未建模参数写成真实测量结果。三相电源端子和电机区暂为预留；串联分压网络、不稳定回路及短路有明确反馈，不生成猜测的灯亮度、电流或转速。故障后停止计算属于软件反馈策略，不代表真实断路器的动作曲线。

增加数值仿真前，需要补充参数来源、单位、适用条件和误差范围，再决定模型实现方式。

## 外部数据与版本

导入文件及本地恢复内容均先通过 `parseProject`。当前存档格式为 `format: "wirebench-2d"`、`version: 1`，校验有效端子、唯一导线编号、重复端点对、颜色和坐标。限制为 2 MiB UTF-8、500 根导线、每根最多 64 个拐点，坐标范围为 −3000～6000。

外部对象按允许字段重建，不直接合并到应用状态。未知字段、未知版本、非法颜色、非有限数值和污染字段均报错；失败导入不应覆盖用户当前方案。保存失败应在界面提示，不得显示“已保存”。

本地内容损坏或版本未知时，`readStoredProject` 保留原文并返回保护状态，界面可打开空白工作区，但自动和手动保存均不得覆盖旧内容。读取不产生写入，开发模式重复初始化不会新增备份或覆盖数据；每次保存前重新检查现有内容。浏览器禁止访问、读写异常和空间不足分别展示实际原因，当前方案仍可导出文件。

受保护原文保留在当前网址的浏览器本地存储键 `wirebench-2d.project.v1`。恢复时先导出当前工作区，再在开发者工具的“应用 / 存储 → 本地存储”中复制该键的完整值到文件。保留这份原文后，可修复文件或用兼容版本打开；确认备份完整后才移除原键并刷新，恢复自动保存。应用不会自动清除受保护数据。

新增需要持久化的字段或改变端子语义时，应明确存档兼容策略。保留旧版本解析，使用可测试的迁移函数生成新版本；迁移无法保证原接线语义时保留原文件并提示。禁止静默忽略未知字段、删除不认识的导线或通过重编号掩盖兼容问题。

## 视图展开与全屏

用户导线的透明点击区域采用固定屏幕宽度，与 `wireSelection.ts` 的屏幕像素容差一致。命中判断使用当前显示折线，包括正在拖动的拐点；候选始终按原始导线数组顺序排列。重复点击同一处可依次选择附近重叠或交叉的导线，也可通过「下一根」按钮切换。轮选状态只在画布内存中保存，不进入接线历史或存档。

接线进行中，点击已有导线或器件本体由画布添加拐点，不改选导线或操作器件；点击目标端子完成连接。空白处在非接线状态下取消选择。中键及平移模式的事件统一传给画布，右键不启动操作；轻点拐点不提交未变化的线路。键盘端子激活忽略长按重复。

`benchViewport` 统一缩放边界，保证低于 35% 的适配比例继续缩小时不会反向放大。初始及点击「适应画布」后自动适配大小；手动缩放或平移后，侧栏、窗口及全屏变化保持原缩放和画布中心。视图变化不进入接线历史。

选中线的可见图层置顶并缓慢明暗变化，普通未选中线适度淡化，故障线保持可见；选中线两端有静态端子标记。交互节点保留原顺序，键盘焦点沿导线显示，避免 SVG 包围盒轮廓和 Tab 次序改变。减少动态效果时保留加粗、描边与端点标记，关闭闪烁。不自动错开或移动已有路径，显示重叠与交叉仍不代表电气连接。

左侧导航由 App 的 `nav` 状态控制，切换入口始终保留在页头。窄窗口使用覆盖层，关闭导航不卸载实验台。全屏通过 `useBenchFullscreen` 申请最外层 app 元素的标准 Fullscreen API；不可用或拒绝时，继续采用页面内铺满，并明确提示。Esc、按钮退出和 `fullscreenchange` 均同步视图状态。

全屏仅通过样式隐藏页头、两侧面板和页脚。画布、仿真、接线历史及弹窗保留在同一组件树中，不能通过重挂载实现切换。电源旁的重置菜单与当前示例条的退出实验按钮在全屏时仍可用。退出全屏恢复原侧栏状态；全屏状态不写入接线存档。

指南、原图和清空确认共用原生 `Modal`，调用 `showModal()` 限制焦点并隔离背景。关闭后恢复触发按钮焦点，弹窗内 Escape 在到达全屏快捷键前消耗。App 编辑快捷键忽略弹窗、菜单、已消费事件及可编辑输入，防止后台删线或撤销。

左侧「从一个实验开始」和「台上器件」分别保存展开状态，独立折叠；这些视图状态不影响接线和仿真。语言菜单在普通页头和全屏工具栏共享同一组件。

## 国际化与领域数据

系统文案集中到 `src/i18n` 的 ui、bench、messages 子词表。中文键集合提供 `TranslationKey` 类型，英文完整对应；普通组件经 `useI18n` 取文案，纯展示适配器直接使用不依赖 React 的 `catalog.ts` 中的 `translate`。

故障和校验结果携带 `MessageDescriptor`，操作记录保留代码和参数，在当前语言下格式化。这样切换语言能够更新已产生的提示，而不重新执行电气计算。兼容字段和外部错误原文不作为识别错误类型的依据。

语言偏好只写入 `wirebench-2d.locale`；接线存档仍使用 `wirebench-2d.project.v1`。器件 ID、端子编号、导线端点、文件格式和用户方案名称均不依赖语言。Provider 仅负责语言状态、偏好保存和页面 `lang`。扩展规范见 [中英文国际化](INTERNATIONALIZATION.md)。

## 全局外观

`src/theme/provider.tsx` 管理浅色/深色选择，使用独立的 `wirebench-2d.theme` 偏好键并同步同源标签页。`src/theme/tokens.css` 定义界面和画布的语义色。`ThemeToggle` 是直接切换按钮，点击或聚焦后按 Space/Enter 生效，图标、提示和可访问名称表达下一目标；`LanguageMenu` 继续使用 `IconChoiceMenu` 的语言选择菜单。主题 Provider 保持组件树稳定，切换时不修改接线、存档或仿真状态；器件材质、灯色、导线颜色和原始照片保留其含义。扩展规则见 [明暗模式](THEMING.md)。
