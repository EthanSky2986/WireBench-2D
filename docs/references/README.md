# 器件与布局依据

本项目的设备种类、排列与教学接线方式来自项目需求及开发阶段提供的实验台资料。当前发布准备已排除全部用户提供的照片、商品图片、手绘图及其副本；本目录不分发这些资料，也不授予其再分发许可。

应用中的「端子布局」是由当前代码数据生成的矢量示意图。它使用正式实验台相同的位置和端子列表，并提供可展开的器件及端子文字清单，不依赖原始图片文件。

## 实现中的依据

| 内容 | 唯一来源 | 说明 |
| --- | --- | --- |
| 器件、端子与触点 | `src/sim/model.ts` | 完整端子 ID 由器件 ID 与局部标签组成；标签相同不等于电气相连。 |
| 器件与端子排位置 | `src/layout.ts` | 仅决定二维布局与固定线图形，不决定通断。 |
| 端子布局示意图 | `src/components/LayoutReference.tsx` | 从上述数据生成，不另存一份器件或接线定义。 |
| 正式器件外观 | `src/components/RefinedDeviceArt.tsx` | 项目内 SVG 图形；外观不表示额定参数、厂家认证或实物精度。 |

## 已落实的布局与操作要求

- 学生在端子排之间接线；器件与对应端子的引出线视为预接好。
- 实验台包含三个接触器、两个热继电器、三个按钮、急停、两个行程开关、三盏指示灯、教学电源及电机预留区。
- 下排从左到右依次为电机端子、SQ1 与 SQ2 端子、两只 SQ 本体，以及按钮及急停端子区。
- SQ1 与 SQ2 各有一组 NC 和一组 NO。界面仅画出固定孔进入下方横槽的短引线，入槽后的内部线路隐藏。
- SB1、SB2、SB3 各四位端子，急停两位端子，共十四位连续安装，组间保持电气独立。OP 是急停区域的展示标记，存档仍使用 `ESTOP`。
- 元器件外观和指示灯效果用于辨认状态；导线的颜色、交叉与重叠不改变拓扑。

## 尚未确认或未建模的事项

SQ 的 `NC1/NC2/NO3/NO4` 是当前软件的稳定标识，末尾编号未作为所有实物型号的通用定义。接触器线圈与指示灯的实物额定电压、热继电器的型号和整定范围不统一假定。L/N 当前表示教学控制电源的连接关系，不输出真实电压、电流、温升或保护动作曲线；三相与电机运行为预留能力。

后续增加型号或实物参数时，应记录可核实的参数来源、适用范围与许可条件。维护者提供的新图片须明确再分发权利；未经确认的图片不进入公开内容。
