# 明暗模式

界面提供浅色（`light`）与深色（`dark`），默认浅色。正式实验台、小样页及全屏工具栏使用同一个切换按钮：点击，或聚焦后按 Space/Enter，直接切换明暗。图标、悬停提示和可访问名称表示下一次切换的目标。设置独立保存，切换外观不改变运行状态、导线或项目名称。

## 职责与数据边界

- `src/theme/provider.tsx` 管理选择、浏览器偏好与跨标签同步，通过根元素的 `data-theme` 和 `color-scheme` 应用主题。
- `wirebench-2d.theme` 只保存外观选择，与语言键 `wirebench-2d.locale` 和项目键 `wirebench-2d.project.v1` 分离。存储不可用时，当前窗口仍能切换；非法值回退浅色。
- `src/theme/tokens.css` 定义两套界面语义色和画布色。组件消费变量，不读取存储、不在渲染中修改主题。
- `ThemeToggle` 使用原生按钮直接切换，不打开菜单；太阳表示切换为浅色，月亮表示切换为深色。提示文案进入中英文词表。
- `LanguageMenu` 仍使用 `IconChoiceMenu` 提供语言选择菜单，其焦点和键盘行为独立于主题按钮。

## 颜色原则

界面背景、文字、边框、选中状态和弹窗使用主题变量。深色模式有独立的背景层次，重要文字、工具和端子始终清楚；不通过整页反色或降低整体透明度实现。

器件的塑料、金属、灯罩和用户选择的导线颜色属于内容固有色，主题切换不改变它们的意义。画布底板、固定引出线与辅助高亮可以适应背景；不能将主题色解释为电位或让装饰光晕参与仿真。程序生成的参考图保留自身配色。

新增界面时优先使用现有语义变量。新增材质或画布色时同时提供浅色、深色值，并在真实 SVG 中检查；不要只检查页面外围。

## 验收要求

1. 两个页面及全屏均可通过点击、Space/Enter 直接切换；图标、悬停提示和可访问名称正确表示下一目标，焦点保留在按钮上。
2. 自锁运行时切换，线圈、灯与导线保持；刷新后外观保留，原有项目恢复规则不变。
3. 检查跨标签同步、中英文提示、键盘操作、侧栏和弹窗；语言菜单仍按原有方式选择语言。
4. 检查暗底上的灰色/蓝色导线、端子编号、灭灯和亮灯，以及程序生成的端子布局参考图的正常显示。

以上是主题改动时的检查要求，不代表已经覆盖所有浏览器和使用环境。
