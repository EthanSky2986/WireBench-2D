# 视觉样品规范

先通过少量视觉样品确定器件、灯光、导线与端子的共同表现方式，再应用到整张实验台。本文记录设计约束与扩展目标；新旧对比小样入口为 `/?preview=materials`，实际检查见 [验收记录](VERIFICATION.md)。

2026-10-01：正式实验台与右侧详情已采用新版器件，覆盖 8 类、16 个器件。接触器、按钮、三色灯沿用已认可小样；热继电器、SQ、急停、电机接线盒和电源采用同一套壳体、金属与底板材质。全局明暗模式已接入。圆弯导线材质仍仅在小样，正式画布保留折线和原有用户路径。

## 视角与材质

- 保持二维正视图，器件位置、端子编号和接线关系清楚可辨。不添加透视倾斜或改变接线认知的三维旋转。
- 元件与端子排的相对排列以手绘及用户确认的实物图为准，不能为了整齐默认将每组端子排放到对应器件上方。SQ 区域从左到右排列 SQ1 端子排、SQ2 端子排、SQ1 本体、SQ2 本体；SQ 端子到下方横槽的短固定引线可见，入槽后的内部预接线隐藏，端子、本体和用户接线保持可见。
- SQ 右侧的 SB／急停端子按实物组成连续 14 位端子排，共用底座，依次标明 SB1、SB2、SB3、OP／E-STOP 四组（4＋4＋4＋2）。OP 是照片中的急停展示标记，内部设备 ID 仍为 ESTOP；连续安装不表示不同端子电气相连。
- 光照统一来自左上方。塑料外壳、金属螺钉、灯罩和导线分别使用一致的高光与阴影规则，避免每个器件拥有不同光源。
- 实验台、端子壳和器件外壳以中性灰为主，通过明度、边缘与表面材质区分层次，避免整张画布偏绿。
- 品牌绿用于主要操作、选中和界面强调。灯的绿、导线的绿是器件颜色，不因品牌色统一而改写；任何颜色都不代替电气状态或端子说明。
- 阴影只辅助辨认厚度与接触位置，控制范围和对比，不能覆盖端子文字、插孔和细导线。

## 指示灯

灭灯状态保留暗色透明灯罩、较窄高光和清晰外圈，让用户仍能辨认灯色。不得将灭灯简单画成黑洞，也不得保留与亮灯相同的强发光区域。

亮灯采用三个相互配合的层次：靠近白色但不过曝的亮心、能辨认原灯色的色边、局限于灯罩周围的柔和光晕。黄、绿、红灯保持不同色相，避免亮心覆盖全部灯罩后只剩同一种白色。

发光由仿真结果控制。光晕用于帮助观察亮灭，不宣称表示真实电流、功率或亮度测量。常亮状态以稳定显示为主，不默认闪烁或呼吸。

## 按钮与接触器反馈

- 普通按钮按下时通过按钮面下沉、高光位置和边缘阴影变化表达机械动作，松开立即恢复。机械反馈与指示灯发光独立，按钮按下本身不产生未建模的背光。
- 急停保持其锁定状态，点击复位后才恢复外观；不能沿用普通按钮松开即复位的动画。
- 接触器使用局部衔铁或状态窗变化表现吸合与释放，保留端子和主体位置。外观变化读取现有线圈结果，不通过动画结束事件驱动触点。
- 行程开关和热继电器测试反馈遵循各自操作状态，避免用统一的整机发光代替机械动作。

## 导线与接线端子

导线以柔和圆弯代替尖锐折角，保持外皮主色、轻微暗侧和细高光，形成清楚但克制的材质。圆角属于显示处理，不改写用户拐点、端点 ID 或存档中的线路；路径命中区域与实际显示保持一致，交叉仍不相连。

选中和故障标记使用额外边线、轮廓或明确提示，不能让高亮颜色被误认为线本身改色。复杂线路中优先保证可追踪性，避免强阴影与过粗高光使相邻导线黏合。

正式画布已采用沿线选择提示，移除导线的矩形焦点框。选中线绘制在其他导线上方，以 2.8 秒周期缓慢明暗变化且始终可见；加粗和两端标记帮助追踪。其余普通用户导线适度淡化，故障线保持可辨。键盘焦点沿线路描边；系统启用减少动态效果时停止动画，保留静态提示。

重叠或交叉位置重复点击可轮换选中导线，简短提示显示附近导线数量，并提供「下一根」按钮。候选依据实际折线及屏幕像素距离确定，缩放不会放大点击范围；选择不改变线路、颜色与端子 ID。现阶段保留已有走线，自动平行错位与交叉跨线桥仍为后续选项；圆弯材质仍只在小样页。

端子是接线时最高优先级的可读层：编号、插孔中心、选中状态与接入标记始终清楚。器件发光、导线材质、阴影和固定配线不能压住端子标签或降低点击区域的辨识度。视觉层级调整不得新增或移除电气连接。

## 动效、性能与可访问性

- 逻辑结果即时更新，动画只呈现已经发生的状态。不能等待过渡完成后再吸合线圈、切换触点、熄灭指示灯或释放按钮。
- 使用短而克制的位移、透明度或高光过渡，避免持续闪烁、整台抖动、装饰性电流奔跑效果。
- 响应 `prefers-reduced-motion: reduce`：移除非必要过渡和持续动画，仍以静态位置、颜色、轮廓和文字表达相同状态。
- 以最多 500 根导线为性能约束。导线材质优先采用可复用的描边或轻量渐变，不为每根线配置大范围模糊、阴影滤镜或独立循环动画。
- 局部光晕只用于少量实际发光的器件，限制滤镜区域。平移、缩放、拖动拐点和端子交互不能因装饰效果明显迟滞。
- 颜色变化同时保留形状、位置或文字反馈。中英文标签都须能在当前缩放层级辨读，聚焦轮廓不能被视觉效果遮住。

## 样品范围与验收顺序

1. **单器件样品：** 一盏指示灯的亮灭、一个按钮的按下与释放、一个接触器的吸合与释放，统一光源与材质。
2. **接线局部样品：** 一段端子排、固定引出线、两根有圆弯与交叉的用户导线，验证标签、插孔、连接和选中状态的优先级。
3. **组合检查：** 将样品放回实验台的实际背景和缩放环境，对比中英文、正常视图与全屏，以及浅色和深色导线。
4. **扩展前检查：** 观察密集线路及 500 根导线场景的拖动与缩放，检查减少动态效果偏好；通过后再推广到其余器件。

本轮沿用现有仿真、器件定义、操作语义和存档格式。视觉样品不重写电气算法，不修改固定配线映射，不变更保存文件，也不以替换器件组件的方式重置运行状态。后续沿用用户已认可的改进外观。

## 第一组样品的实现边界

- `src/preview/sampleCircuit.ts` 定义普通自锁接线与仅用于样品的坐标；`useSimulation` 是新旧视图共用的唯一行为来源，样品不访问项目存储。
- `RefinedDeviceArt` 是只消费设备状态的正式 SVG 图形，覆盖全部八类器件，无旧图形回退；`DeviceArt` 保留用于新旧对比。正式画布与详情面板共用新版组件，保持 160×160 坐标系、模型 ID 与固定引线锚点。
- `src/rendering/wireGeometry.ts` 从原控制点生成圆弯路径，`WirePath` 绘制轻量材质；命中区域使用同一几何函数。颜色、投影和圆角均不产生电气连接。
- 主页面按需载入预览模块；正式实验台直接使用新版器件，保留折线路径编辑方式。新增器件外观需要在正式入口核对普通/全屏、明暗、动作与释放状态，不以小样可见代替正式接入。
